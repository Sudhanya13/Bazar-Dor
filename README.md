# বাজার দর / BazarDor

---

## Short Description

**BazarDor** is a comprehensive, user-centric price-tracking and comparison platform designed for daily grocery and household essentials. It empowers consumers to monitor real-time market prices, track historical trends, and find the best local deals to make informed and economical shopping decisions.

---

## Technologies Used

- **Frontend:** React.js / Next.js, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB / PostgreSQL
- **Scraping & Data Pipeline:** Python (BeautifulSoup / Scrapy) for aggregating market data
- **Deployment & Hosting:** Vercel (Frontend), Render / AWS (Backend)

---

## 5 Key Features

- **Real-Time Price Updates:** Instantly check current market rates for vegetables, fish, meat, and daily commodities.
- **Price Trend Analytics:** Visualize historical price fluctuations through interactive charts to buy at the right time.
- **Location-Based Comparison:** Compare prices across different local markets and supermarkets in your area.
- **Smart Shopping List:** Create a custom grocery list and automatically calculate the estimated total cost across preferred vendors.
- **Community Crowdsourcing:** Allow users to report and verify local market prices to keep data accurate and community-driven.
